   releases reports the same "0.3.0dev"), and serverInfo is not shown to the

   [x] 17.1. Build ID: capture `git describe --always --dirty` at build time;

   [x] 17.2. Report the build ID in serverInfo.version.
   [x] 17.3. Report it in the `instances get` reply.
   [x] 17.4. Report it in the initialize `instructions`, which the client
      shows to the model every session.
   [x] 17.5. Keep it out of `nowplaying` (the most frequent call; it would
